# Oppikofer • Studio Web — Portfólio & Simulador Interativo

Portfólio oficial de **Wallace Oppikofer** (Desenvolvedor Frontend), reunindo 10 aplicações web responsivas Mobile-First, comparativo interativo, simulador dinâmico de projetos por nicho e visualizador executivo de propostas comerciais.

🔗 **Acesse ao vivo:** [oppikoferstudioweb.vercel.app](https://oppikoferstudioweb.vercel.app)

## ✨ Funcionalidades Principais
- **Vitrine de 10 Projetos Reais:** Agrupamento por nicho, filtros por segmento e navegador compacto no mobile (`< 1 / 10 >`).
- **Simulador Dinâmico de Projetos (`#simulador`):** Seleção de escopo por nicho (Landing Pages, Catálogos, Sites Institucionais, Convites e Demanda Personalizada) com montagem automática de resumo estruturado para WhatsApp.
- **Visualizador de Propostas (`proposta.html`):** Decodificação de links compactos (`Base64URL` / `LZString`) com fluxo de aprovação e checklist técnico.
- **Experiência & Animações:** Rolagem suave com **Lenis** e animações **GSAP ScrollTrigger** (incluindo efeito *word-scrub* na seção Sobre).

## 🛠️ Tecnologias Utilizadas
- HTML5 Semântico
- Tailwind CSS
- JavaScript (ES6+)
- GSAP + ScrollTrigger & Lenis Smooth Scroll
- LZ-String (compressão de URLs)
